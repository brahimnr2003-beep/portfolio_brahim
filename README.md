# Portfolio · Brahim

Vite + Three.js. Retrato de partículas → red neuronal con los proyectos → túnel de salida → contacto.

## Arrancar
    npm install
    npm run dev      # http://localhost:5173
    npm run build    # genera dist/

## Dónde editar
- `index.html`: página final (email, GitHub, LinkedIn, CV, textos).
- `src/main.js`: proyectos (nombre, color, enlace) y recorrido del scroll.
- `src/style.css`: estilos.
- `src/portrait-points.json`: puntos del retrato (generados desde tu foto).
